## 发布前尚需完成

1. **历史邮箱隐私**：Git 作者/提交者元数据存在非 noreply 邮箱。
   本地运行 `git log --all --format='%an <%ae> / %cn <%ce>'` 查看。
   本次未改写历史或强推。若不希望公开该邮箱，先备份，再统一改写所有相关
   分支/标签并协调现有克隆；工作树删除或新增 .mailmap 不会清除原始对象。
2. **许可证与第三方声明**：项目 LICENSE 为 GPL v2。分发包须携带许可证并提供
   与实际二进制对应的完整源码及构建说明；新打包脚本只补齐本项目说明，
   仍须逐项核对第三方依赖及随包运行库的再分发条款/声明。
   发布源码应包含所有本地改动，并为该发行版本建立可对应的公开版本记录。
3. **商店核验**：在 Partner Center 核实清单身份、发布者、版本以及 runFullTrust
   用途说明；本地无法验证账户中的配置或批准状态。
   Store 提交 APPX；带开发证书和安装脚本的 ZIP 用于侧载测试。
4. **隐私入口**：发布 PRIVACY.md 的稳定公开 URL，在商店资料填写并核对
   应用内可访问入口。日志含主机、用户名、路径与异常细节，不能直接公开上传。
5. **安装实测**：重新打包后在干净 Windows 11 测试账户验证 Store/安装入口启动、
   升级、卸载、文件选择、SSH/SFTP 与高 DPI/无障碍，并执行 WACK。
   本次未导入证书、安装应用或运行交互式真实 SSH 测试。

## 安全代码观察

保存密码与密钥口令使用 DPAPI CurrentUser；会话文件保存主机、用户名与私钥路径，
这些仍属于隐私数据。主机指纹不匹配时需要明确用户决定；没有提示回调时拒绝。
SCP 回退命令对路径使用单引号并转义内部单引号；未发现直接拼接未转义路径的证据。
日志与崩溃记录会写异常及连接信息，当前没有通用脱敏层；提交诊断前必须人工审阅。

历史规则扫描 485 个文件版本未命中常见私钥、GitHub/OpenAI 令牌、AWS access key
或含密码 URL。规则扫描无法排除任意明文密码、其他提供商令牌或历史二进制中的秘密。
Git 提交邮箱不属于这些内容规则，已单独报告。
