# SurgeLink 全项目审查与加固记录

日期：2026-10-24。版本：1.0.2.35。范围：当前工作区整个解决方案、测试、构建发布脚本和项目文档。

本轮采用全项目静态检索、关键路径逐段检查、故障场景回归测试和 Release 构建。
重点检查了资源所有权、并发、取消、数据写入和 Agent 接管边界。这里记录的是已验证的
修复和验证边界，不能据此承诺所有运行环境下没有缺陷。之前的审查文档保留为历史记录，
本轮没有直接沿用其中的“无问题”结论。

## 已修复的问题

| 优先级 | 问题与触发条件 | 修复及验证 |
|---|---|---|
| P1 | 两个关闭调用竞争时，后一个调用在前一个仍等待 Agent I/O 时提前返回；关闭前回调失败后，标签永久停留在关闭状态 | `WorkspaceStore` 按标签共享关闭任务；关闭前失败恢复可重试状态；各资源清理分别尝试。回归测试覆盖重复关闭、等待排空和失败重试 |
| P1 | 人工输入、停止接管、关闭窗口同时撤销授权时，重复撤销没有共同等待在途操作；取消回调抛异常时也可能跳过等待 | `AgentGateway` 共享撤销任务，先删除句柄再排空；取消回调失败也继续等待；排空期间禁止重新授予同一连接。测试覆盖共同等待和异常回调 |
| P1 | 切换权限正在等待旧操作结束时，“停止全部接管”之后仍可能重新授权 | `AgentWorkspaceService` 串行化授权变更，用停止代数使旧请求失效，并重新核验会话、关闭状态及人工输入版本；授权后再次检查订阅前的输入窗口。停止按钮在其他操作等待时仍可使用。集成测试通过真实命名管道验证停止后保持未授权 |
| P1 | Agent 编码输入等待终端锁时，人已经输入，旧输入版本仍可能写入 | 写入前通过比较交换原子预留输入版本。确定性线程测试让 Agent 阻塞在模拟器锁上，再插入人工输入，验证 Agent 内容没有写入 |
| P1 | 多实例配置保存各自使用过期缓存，丢失其他实例的会话、凭据、可信主机或设置 | 持有跨实例文件锁后重新读取，再执行增量修改；读取可观察最新磁盘状态。测试覆盖并行独立实例及保存/删除交错；设置的字段更新合并最新状态 |
| P1 | 所有写入复用固定 `.tmp` 文件，保存竞争或失败可能破坏另一次写入；损坏文件可能被当空数据覆盖 | 临时文件改用 GUID，写完刷盘再替换，失败清理临时文件；增量更新使用严格读取，失败时保留原文件。测试覆盖替换失败、损坏 JSON 和临时文件残留 |
| P1 | 远程编辑器覆盖加载之后发生的外部修改 | 保存原始字节 SHA-256，写入前及提交前重新检查；相同文件系统实例的写入串行化，冲突时保留编辑内容并显示提示。测试覆盖外部修改、竞争保存、提交前冲突、临时文件清理和连续保存的编码/BOM |
| P1 | SCP 的普通 `mv` 会覆盖现有目标，或把源文件移入同名目录 | 使用禁止覆盖及精确目标语义，并检查源是否实际消失；不支持这些选项的服务端明确失败。实际 Git Bash 测试覆盖带单引号的路径、已有文件、已有目录及成功重命名 |
| P2 | SSH 能力 getter 和异步 SFTP/SCP 建连结果可能在会话释放后重新发布资源；过早释放信号量导致在途操作 Release 失败 | 能力创建、关闭和连接结果发布使用生命周期锁，拒绝并释放迟到连接；仍被等待者引用的信号量交给对象回收。三个确定性测试覆盖关闭与 Terminal/FileSystem/Monitor getter 竞争；真实迟到建连仍需服务器场景验证 |
| P2 | 排队中的交互取消后仍等待前一个弹窗；当前交互取消可能阻塞连接取消 | 取消时移除尚未显示的项，调用者立即结束；当前原生弹窗仍由关闭回调完成其生命周期，防止后续弹窗重叠。测试覆盖预取消、排队取消和当前项取消 |
| P2 | SSH 内部命令在结束前积累所有输出，大目录或异常输出可能大量占用内存 | 同时读取 stdout/stderr，捕获上限分别为 8 MiB/2 MiB，超限失败并关闭命令，避免返回截断目录。测试覆盖边界、超限、多字节与取消；完整通道过程需真实 SSH 压力验证 |
| P2 | 审计订阅者异常可能丢失已完成操作的响应；管道断开竞争可能终止服务；退出时未统一释放服务图 | 隔离审计订阅者，保护管道 Disconnect，合并重复 Dispose；退出释放 Agent、工作区、会话管理器和日志，并在单项失败后继续清理。观察者隔离和后续操作有回归覆盖，桌面退出需运行时复核 |

P1 表示可能造成数据丢失、授权语义失效或连接清理顺序错误；P2 表示异常路径、资源或维护风险。
“已修复”表示相应代码路径已修改并完成表中所述验证，不表示所有传输组合都已实测。

## 剩余边界与发布前验证

1. 本轮没有使用真实远端账号、串口硬件或长时间桌面 UI 操作；还需要实测断网重连、
   连接/退出交错、大文件取消、SFTP 不可用时的 SCP 回退、SSH 大输出及连续接管/人工抢占。
   x64 已构建，ARM64 运行及安装/升级没有在本轮复验。
2. SFTP 没有服务端条件替换原语。最后一次指纹验证到 rename 之间，外部写入仍可能竞争。
   当前实现能检测常见覆盖冲突，不能提供跨客户端的严格事务。其他文件系统实例和其他进程
   也不共享本地远程写锁。若要严格保护，需要服务端协议支持或双方约定锁。
3. 传输队列最多等十秒后继续关闭连接；断网时远程临时文件可能保留，清理是尽力而为。
   任意第三方协议插件若完全忽略取消且永不结束，Agent 为保证关闭顺序仍会等待其在途操作。
4. SSH.NET 的管道读取/结束行为已按对应版本源代码核对：
   [SshCommand](https://github.com/sshnet/SSH.NET/blob/2026.0.0/src/Renci.SshNet/SshCommand.cs)、
   [PipeStream](https://github.com/sshnet/SSH.NET/blob/2026.0.0/src/Renci.SshNet/Common/PipeStream.cs)。
   捕获限额约束的是应用保留的数据，不能视为整个进程的硬内存上限；SDK 接收缓冲、字符解码
   和多条并行命令仍有额外开销。
5. 本地管道以当前 Windows 用户为边界，不区分同一用户运行的不同应用。Agent app 负责执行策略，
   SurgeLink 保留用户授权范围、人工输入抢占和连接生命周期约束，符合本会话已确定的产品方向。
6. 存储文件锁同步等待上限五秒；外部进程长期占用时保存会失败。损坏文件先保留证据再人工
   修复/恢复，后续可以增加专门的恢复界面。设置窗口整份草稿替换和显式 `ISessionStore.Save`
   仍是最后写入者生效；不能把字段级增量合并解释为任意用户编辑都能自动合并。

建议把上述真实环境场景作为下一次正式发布前的验收项。当前工作区的自动化验证已覆盖本轮
确认的问题，剩余项在这里明确区分为环境验证和协议能力限制。
